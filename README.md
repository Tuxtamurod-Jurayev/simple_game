# Command & Conquer: Mini-Generals 🎮

Brauzerda ishlaydigan, ortiqcha o‘rnatishlarni talab qilmaydigan, *Command & Conquer: Generals* uslubidagi yengil real vaqt strategiya (RTS) o‘yini prototipi (1-bosqich).

## 🚀 Texnologiyalar
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Renderlash mexanizmi:** HTML5 Canvas 2D
- **Fayl tuzilmasi:** Yagona mustaqil `index.html` fayl

## 🎯 1-bosqich imkoniyatlari
- **UI Panel:** Mablag' ($1000), Energiya (10/10), Tanlangan birlik holati va taktik status ko'rsatkichi.
- **Harbiy maydon (Canvas):** 900x600 o'lchamdagi to'q yashil harbiy xarita va koordinatali setka.
- **Obyektlar:**
  - **HQ (Bosh bino):** Xaritadagi asosiy baza (animatsiyali radar bilan).
  - **Ishchi (Worker):** Resurs va qurilish birligi (tezligi 2.0).
  - **Jangovar Tank:** Taktik jangovar birlik (tezligi 1.5).
- **Boshqaruv:**
  - **Tanlash:** Chap tugma bilan birlik yoki binoni tanlash (sariq hoshiya).
  - **Harakatlanish:** Tanlangan birlik mavjud bo'lganda bo'sh joyga bosib yo'naltirish (taktik nishon animatsiyasi).
  - **Qurilish:** `Q` tugmasi orqali hisobdan $500 sarflab yangi **Kazarma (Barracks)** qurish.

## 🕹 Ishga tushirish
Hech qanday o'rnatish shart emas. `index.html` faylini istalgan brauzerda oching.
